# Database Testing

ParaBank is a public demo and direct access to its server database is not provided. Nothing in this folder queries the ParaBank database. Instead, the SQL test cases from the workbook run against a **local synthetic dataset** (SQLite) with fully fictional customers, accounts, and transfers, so the checks themselves — referential integrity, balance reconciliation, balanced transfer posting, duplicate detection, history completeness, username uniqueness — are genuinely executed and reproducible.

## Contents

| File | Purpose |
| --- | --- |
| `schema.sql` | Tables: `customers`, `accounts`, `transactions` |
| `seed_data.sql` | Fictional seed data; documents the seeded transfers, the expected per-account transaction counts, and the balance arithmetic |
| `queries/DB-*.sql` | One check query per workbook SQL test case |
| `run_sql_tests.py` | Builds a fresh `synthetic_banking.db`, loads schema + seed, runs all six checks, prints actual output and a verdict per case |
| `synthetic_banking.db` | Generated by the runner; safe to delete and regenerate |

## Run

```bash
python run_sql_tests.py
```
